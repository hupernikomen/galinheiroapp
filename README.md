Custo Fixo
É o valor dos gastos da fase de criação (antes das galinhas começarem a botar), diluído na produção total estimada de ovos.
Exemplo:
Você gastou R$ 4.000 para criar o lote até a 18ª semana.
O lote deve produzir 20.000 ovos na vida.
Custo fixo = R$ 4.000 ÷ 20.000 = R$ 0,20 por ovo
Esse valor quase não muda. Só sobe um pouco se alguma galinha morrer (porque a produção estimada diminui).

Custo Variável
É o valor dos gastos depois que começou a postura (ração, medicamentos, etc.), dividido pela quantidade de ovos já produzidos.
Exemplo:
Gastou R$ 1.500 na fase de postura.
Já coletou 6.000 ovos.
Custo variável = R$ 1.500 ÷ 6.000 = R$ 0,25 por ovo
Esse valor muda conforme você registra novos gastos e novas coletas.

Custo Total
É a soma dos dois:
Custo Total = Custo Fixo + Custo Variável
No exemplo: R$ 0,20 + R$ 0,25 = R$ 0,45 por ovo
Esse é o valor real que cada ovo está custando até o momento.
O preço sugerido é esse custo total + a margem de lucro que você definir.
